CONCERT COMPASS — CURRENT PLAN (clean export, 2026-08-28)
==========================================================

1. WHAT WE'RE BUILDING
---------------------
A web app where a user uploads many raw concert videos (long, shaky, repetitive phone recordings) and gets back a polished vertical highlight reel. 2.0 (owner-endorsed) makes it an AI-assisted editing engine, not a clip-concatenator: it analyzes footage at the moment/segment level — a 60s clip may contain one useful 1.8s moment; extract that moment — and selects/edits like a skilled social-video editor would for TikTok/Reels/Shorts.

Quality standard (the non-negotiable): the output must feel like "someone who understands social video watched all my footage and edited this for me" — NOT "software combined videos and added transitions." Clean, well-paced, excellent moments with intentional cuts beat mediocre footage with elaborate effects. Nothing choppy is ever acceptable.

2. THE 2.0 CORE PRODUCT BEHAVIOR (OWNER'S PLAN)
-----------------------------------------------
1. Segment-level analysis of every upload -> per-segment metadata: start/end, duration, sharpness, stability, exposure, performer visibility, framing, motion, stage-light change, crowd, audio energy, applause/cheer, beat/onset, uniqueness, highlight score. Reject/penalize floor/ceiling, shake, obstruction, blur, near-black, duplicates, static, redundant composition.
2. Diversity-aware highlight selection across ALL media: rank by quality AND variety (wide / close performer / crowd / lighting / high-energy / quiet cinematic), never two consecutive near-identical shots.
3. Editorial story arc: HOOK -> ESTABLISH -> BUILD -> PEAK -> PAYOFF -> END. No black screen / logo / title card at open; branding only subtle at the end.
4. Professional pacing: default ~30s (15/30/45/60). 0.5-1.5s rapid, 1.5-3s normal, 3-5s hero only. Cuts intentional, timed to beats/movements/lighting/crowd.
5. Audio-driven editing: cuts near beats/onsets/chorus/screams/applause; coherent audio bed.
6. Transitions sparingly; default hard cut; optional only when visually motivated (subtle crossfade / match / motion / whip / flash). Never novelty slideshow. Nearly invisible.
7. 9:16 smart reframing (subject-aware, not blind center-crop), gentle animated follow.
8. Edit Modes: Cinematic / Hype / Memory / Music Video / Surprise Me.
9. User control after generation: regenerate, replace segment, lock segment, shorten/lengthen, change style, adjust energy, reorder, choose hook, choose ending, mute source audio, export. Regeneration must be a meaningfully different edit.
10. Architecture - CLIENT-SIDE (owner decision, Aug 2026): analysis + selection run in the browser. No server/FFmpeg pipeline now. The EDL + optional server render is a documented, deferred path only. Fast, private (footage never leaves device), zero infra cost.
